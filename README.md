# 🐝 BeeSmartApp — Система управління промисловою пасікою

**BeeSmart** — це сучасна інформаційна система (ERP + IoT) для цифровізації процесів на промисловій пасіці. Вона дозволяє відмовитися від паперових журналів, автоматизувати облік вуликів через QR-коди, керувати ветеринарними завданнями та отримувати дані з IoT-ваг у реальному часі.

---

## 🛠 Технологічний стек
- **Frontend:** React.js, Vite, Tailwind CSS, Zustand, Recharts.
- **Backend:** Node.js, Express.js, Joi (валідація), JWT (безпека).
- **Database:** MongoDB (NoSQL).
- **Infrastructure:** Docker, Docker Compose, Nginx.

---

## 🚀 Як запустити проєкт

Для запуску вам потрібно мати встановлений **Docker** та **Docker Compose**.

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/zrumyk/BeeSmartApp.git
   cd BeeSmartApp
   ```

2. **Запустіть систему одним кліком:**
   ```bash
   docker-compose up --build
   ```

3. **Відкрийте застосунок у браузері:**
   - **Frontend:** [http://localhost](http://localhost)
   - **Backend API:** [http://localhost:5000](http://localhost:5000)
   - **API Documentation (Swagger):** [http://localhost:5000/api/docs](http://localhost:5000/api/docs)

## 📋 Використання застосунку

### Ролі користувачів:
- **Адміністратор:** Має повний доступ до керування локаціями (пасіками), реєстрації нових вуликів та призначення завдань бджолярам.
- **Бджоляр (Beekeeper):** Працює в полі через мобільний інтерфейс. Сканує QR-коди, вносить дані оглядів (навіть офлайн) та звітує про виконання завдань.

### Основні функції:
1. **QR-ідентифікація:** Скануйте код на вулику, щоб миттєво відкрити його цифровий паспорт.
2. **IoT Моніторинг:** Переглядайте графіки приросту меду на основі даних з електронних ваг.
3. **Офлайн-режим:** Дані оглядів зберігаються локально, якщо на пасіці немає інтернету, і автоматично синхронізуються при появі мережі.
4. **Ветеринарний контроль:** Розподіл завдань за статусами (Pending/Completed).

## ⚙️ Команди та Порти

### Порти:
| Сервіс | Внутрішній порт | Зовнішній порт |
| :--- | :---: | :---: |
| **Frontend** | 80 | 80 |
| **Backend** | 5000 | 5000 |
| **MongoDB** | 27017 | 27017 |

### Корисні команди:
- `docker-compose down` — зупинити всі контейнери.
- `docker-compose logs -f backend` — переглянути логи сервера.
