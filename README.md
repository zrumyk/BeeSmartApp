# 🐝 BeeSmartApp — Система управління промисловою пасікою

**BeeSmart** — це сучасна повнофункціональна інформаційна система (ERP + IoT) для автоматизації процесів на промисловій пасіці. Проєкт розроблений для цифровізації обліку вуликів, контролю ветеринарного стану та моніторингу медозбору.

---

## 🛠 Технологічний стек
- **Frontend:** React.js, Vite, Tailwind CSS, Zustand (state management), Recharts (графіки).
- **Backend:** Node.js, Express.js, Joi (валідація), JWT (авторизація).
- **База даних:** MongoDB (NoSQL).
- **Інфраструктура:** Docker, Docker Compose, Nginx.

---

## 🚀 Як запустити проєкт

Система повністю контейнеризована. Для запуску вам потрібно мати лише **Docker** та **Docker Compose**.

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/zrumyk/BeeSmartApp.git
   cd BeeSmartApp
   ```

2. **Запустіть всі сервіси (однією командою):**
   ```bash
   docker-compose up --build
   ```

3. **Доступ до застосунку:**
   - **Інтерфейс (Frontend):** [http://localhost](http://localhost)
   - **Сервер API:** [http://localhost:5000](http://localhost:5000)
   - **Документація API (Swagger):** [http://localhost:5000/api/docs](http://localhost:5000/api/docs)

## 📋 Використання застосунку

### Ролі:
- **Адміністратор:** Керує пасіками (локаціями), реєструє нові вулики, переглядає журнал оглядів та призначає завдання.
- **Бджоляр:** Працює через мобільний інтерфейс, сканує QR-коди вуликів, вносить дані оглядів (працює офлайн) та позначає завдання як виконані.

### Ключові можливості:
1. **QR-ідентифікація:** Кожен вулик має унікальний код для швидкого доступу до історії.
2. **IoT Моніторинг:** Автоматичне відображення графіків ваги та приросту меду.
3. **Офлайн-синхронізація:** Якщо в полі немає зв'язку, дані зберігаються на пристрої та синхронізуються пізніше.

## ⚙️ Команди та Порти

### Порти:
| Сервіс | Порт |
| :--- | :---: |
| **Frontend (Nginx)** | 80 |
| **Backend (Express)** | 5000 |
| **MongoDB** | 27017 |

### Корисні команди Docker:
- `docker-compose logs -f backend` — перегляд логів сервера в реальному часі.
- `docker-compose down` — зупинка та видалення контейнерів.
- `docker exec -it beesmart_backend node seed.js` — повторний запуск наповнення бази тестовими даними.
